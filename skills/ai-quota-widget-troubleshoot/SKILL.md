# 排查额度监控悬浮窗

先只读取证，确认问题后按用户修复授权处理。未安装时读取目标正式版本仓库根目录SKILL.md，不假定另一技能已装在本机。

## 版本、环境和时间

默认中文。先区分安装类型：**成品版直接运行同目录 `quota-cli.exe --doctor`**，个人状态在 `%LOCALAPPDATA%\AIQuotaWidget`；不需要 Python，不要用全局解释器诊断它。doctor 返回1且提示“未配置”是待配置，不是安装失败。

以下仅用于源码版：从安装目录start.bat获取绑定的Python，避免全局解释器造成依赖误报：

```powershell
& "<start.bat绑定的python.exe>" "<安装目录>\quota_monitor.py" --doctor --data-dir "<安装目录>"
```

doctor离线，不验证网络；公开反馈用它或右键“复制脱敏诊断”。不得索取或公开整份config.json、debug.txt、DPAPI、CLI凭据或含余额JSON。

仍无法定位时，在本机核对debug.txt的app_version、pid、updated、ui_error、errors、success_at、active；将pid与**精确安装路径**对应，区分进程退出、托盘隐藏和旧日志。命令行和本机路径可能包含身份信息，不直接贴公开Issue。

## 依据错误分类，不凭来源名猜原因

| 证据 | 检查方向 |
| --- | --- |
| 缺凭据或明确认证错误 | 核对登录、凭据位置与客户端；只有认证问题才建议重登录 |
| HTTP401 / HTTP403 | 核对认证和权限，GLM还需相应Coding Plan；用户自行配置Key，不回显 |
| 超时 / URLError / TLS错误 | 区分服务端、DNS、证书、网络和既有代理；不默认要求新增代理，不擅改系统网络 |
| HTTP429 | 限流，等待有界退避，不连续手动重试 |
| main / 雷达错误 | 第三方站点网络或格式变化，与个人额度独立，可关闭雷达 |
| tokens错误 | 本地Harness日志或压缩依赖；与余额独立，不把失败当0 |
| 解析/字段异常 | 核对接口结构和版本、脱敏取证，不能用重新登录代替修复 |

`--`、0和旧值不同：未配置、首次查询、接口未提供某窗口均可能显示`--`；0可能是真实耗尽或尚未观察到消费。结合时间和状态判断：

- “待更新”/“旧”：缓存待核验、查询失败或窗口过期等，不把旧数值当新结果。
- 全部卡片关闭：应提示选择账户，不等于“必须登录CLI”。
- 无错误但数字不变：看成功时间，默认15分钟一轮；经用户要求可立即刷新一次。
- DeepSeek今日为0：对比当日基线与最新余额。跨天/换Key会重建起点，早于基线的消费不在估算内；本机token不等同金额，不能据此断言免单或计费故障。

## 窗口与升级

- ✕只隐藏到托盘，点击托盘或重开quota-widget.exe（源码版start.bat）可唤回；“退出”才结束。托盘不可用时应保留主窗。
- 模块缺失/升级无变化：核对实际运行版本，正常退出后重跑**完整安装器**，按runtime-files.txt校验全部模块，不手工只复制三个文件。
- 闪屏、副本、意外退出：记录时间、版本与系统Application Error。v1.3.1修复了菜单同步重绘崩溃，不代表所有类似现象都是该旧问题；不凭截图定根因。
- 安全软件或未知发布者：核对正式仓库资产与校验值，检查实际提示；不因未签名便要求忽略警报或关闭防护。

修复后验证具体失败路径、对应来源的新成功时间及窗口行为。未配置来源可不验证，不强求全部账号。保留个人设置/统计，不结束其他Python或AI会话。

信息不足时请用户提供**脱敏诊断＋操作步骤＋版本/系统/缩放**；需要更细日志时明确本机检查字段并去掉私密内容，不索取整份debug.txt。
