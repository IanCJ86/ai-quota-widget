# AI Quota Widget v1.2.0

Windows 正式版。本次通过 merge commit 合入 DeepSeek Harness 的功能更新与 Codex 的稳定性补丁，保留原始提交归属。

## 主要更新

- 新增 DeepSeek 余额、今日估算消耗、本机 Harness token 统计；新增 Codex 重置券展示与新版运行时识别。
- 完善主题、卡片显示设置、位置/透明度记忆与拖动锁定；保留当前面板布局。
- 修复自动测试窗口意外显示到工作桌面的问题；保留几何去重、拖动防护与必要重绘。
- 修复异常余额污染消费记录、跨日旧数字、重置边界状态及密钥清理失败误报成功。
- token 统计独立进程运行，采用流式跨帧解压、按文件变化缓存和扫描上限，避免拖累余额查询。
- 补齐 Kimi / 雷达异常测试，雷达解析兼容 HTML 属性改序；主题背景自动继承，减少漏更新。
- DeepSeek 计费时段补充2026年官方节假日离线日历；未知年份的可能高峰时段留空，需后续更新。

## 安装与升级

下载 `ai-quota-widget-v1.2.0.zip`，解压后运行 `install.ps1`。需要 Windows、Python 3.10+（含 tkinter）；安装器处理依赖。升级前从托盘菜单退出旧程序，安装到原目录以保留原 config.json。

本版包含 `quota_monitor.py`、`monitor_runtime.py`、`harness_stats.py` 三个运行模块，**不要只替换一个 Python 文件**。安装包不含个人密钥、额度缓存、消费记录、会话日志及审查依赖。

## 验证与边界

- Python 3.10 / 3.14 各92项回归测试通过，0项跳过；新装/升级测试通过。
- 运行性能抽样：token 冷扫描约0.38秒、未变化文件缓存命中约0.012秒，扫描进程峰值工作集约25MiB。结果与本机日志规模有关，不代表所有电脑或长期运行表现。
- 金额是账户余额差额估算，token仅覆盖本机 Harness，二者均不是正式账单。Codex额度仍可能是本机保存的快照，无法证明窗口内每一时刻都实时。
- 发布 GitHub 正式版不等于自动升级已有桌面安装。
