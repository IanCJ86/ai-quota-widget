# AI Quota Widget v1.2.1

Windows 正式版；延续 v1.2.0 的功能和当前面板风格，重点改善结构、版本追踪与单位显示。

## 更新

- App 从1350行降至964行，设置菜单、输入弹窗、托盘与 Windows 原生效果分离为独立组件。主文件仍保留接口适配和渲染，不代表结构债已全部清零。
- 内建版本统一由 app_version.py 提供：右键菜单、`--version`、HTTP User-Agent、Codex RPC 客户端声明及 debug.txt 均引用同一版本。
- DeepSeek 今日 token 明确显示为 `439M tok` 等格式；缺失或关闭时不显示空单位。
- 安装器按 runtime-files.txt 检查并安装全部模块，升级保留原 config.json。查询子进程不加载 GUI/托盘依赖，没有新增动画或驻留查询进程。
- 毛玻璃接口补齐64位句柄类型，非有限 token 数值不会导致界面异常。

## 安装与升级

下载 `ai-quota-widget-v1.2.1.zip`，解压后运行 install.ps1；需要 Windows、Python 3.10+（含 tkinter）。升级时先退出旧面板，再安装到原目录。

**不要仅复制 quota_monitor.py。** 本版必须包含 runtime-files.txt 中的全部9个 Python 运行模块。旧版配置、缓存和消费记录无需删除。

右键菜单应显示“版本 1.2.1”，debug.txt 的 app_version 应为 1.2.1。安装包不包含用户凭据、个人配置、额度缓存、消费记录或本机会话日志；config.json 仅含公共占位默认值。

## 验证

Python 3.10 / 3.14 各106项回归测试通过，0项跳过；两版本新装、升级、模块导入、版本一致性、原配置保留均通过。UI 测试在独立 Windows 桌面运行，不向用户工作桌面显示测试面板。

新主题目前仅为设计计划，本版没有更换皮肤。第三方雷达是预测，Codex 数据可能是本机快照，DeepSeek 今日金额是本地余额差额估算；均沿用既有边界。
