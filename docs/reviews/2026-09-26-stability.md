## 代码修正

- 保留 #8 去重；窗口尺寸应用后才测量圆角；仅位置变化不重建 region；Win32 句柄正确声明，SetWindowRgn 失败释放未移交的 GDI 资源。
- 无效、缺失、NaN、无穷、负数余额在写入消耗记录前拒绝，不产生假消耗。
- token 独立查询进程/状态/缓存，与余额解耦；token 日期、今日金额日期独立核验，跨天不继续显示昨日数字；旧版无日期金额缓存不复用。
- Codex 逐窗口比较当前时间；重置后提前查询，不污染另一窗口和券的状态；已过期快照不会引起紧密重试。
- DPAPI 保存与旧明文清理都必须成功才报告完成；清理 config 与旧 settings 对应字段，文件写失败可见；不删除用户环境变量。
- token 流式跨帧解压、按文件元数据缓存计数，限制单轮时间/单行长度/解压量。缓存不含会话内容，损坏或不完整扫描不返回部分合计。
- Python 3.10 实测发现 zstandard 的 permissive stream_reader 会将某些截断文件当成正常空结果，因此改用标准库同源的 `backports.zstd==1.7.0`，而不是保留不一致的旧兼容实现。[项目说明](https://pypi.org/project/backports.zstd/)
- 安装器同步第三个模块和兼容依赖，并在复制前验证依赖；测试使用假数据/独立临时目录，不读用户会话。
